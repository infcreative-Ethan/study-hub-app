# 全科学习（StudyHub）

给孩子用的安卓学习 APP，平板优先，也支持手机横屏。第一版内容：**英语 · 人教PEP版（新版）三年级上册 · Unit 1**。

## 功能

| 板块 | 内容 |
|---|---|
| 📖 课文 | 按课本页码顺序排列。左边是课本原页，右边是分句文本 + 中文；点哪句读哪句，支持整段播放、单句循环、慢速、隐藏中文。带背景音乐的歌曲/歌谣分句时间是估算的，家长可以在“⋯”里校准。 |
| 🔤 单词 | 按单元学新词（原声发音、音标、中文、例句），学完小测验；按遗忘曲线（1、2、4、7、15、30、60 天）安排复习。复习时随机混合三种方式：看中文拼英文、看英文想中文（不用输入，自己判断）、听音拼写（点字母块，不用键盘）。 |
| 💡 知识点 | 字母、短语、重点句型讲解，点英文可以听发音；配套知识点练习题。 |
| 📝 习题试卷 | 两套单元测试，听力题每题单独播放；自动判分，错题进入错题本，可以重做。 |

多个孩子分开记录进度（首页添加，长按头像删除）。

## 安装 APP

每次推送到 `main` 分支，GitHub Actions 会自动编译，在仓库的 **Releases** 里出现 `StudyHub-N.apk`，下载到平板上安装即可。新版本可以直接覆盖安装，学习记录不会丢。

## 部署资源服务器

APP 里的课本图片、音频、题目都从服务器下载（默认 `http://101.35.43.66:8686/res/`，可在 APP 首页“设置”里修改）。
把资源包 `res` 整个目录（不在本仓库里，单独保存）放到服务器上，让 `http://服务器:8686/res/catalog.json` 能访问到即可。

最简单的方式（服务器上装了 Python3）：

```bash
cd /path/to/server        # 里面有 res 目录
nohup python3 -m http.server 8686 > http.log 2>&1 &
```

如果 8686 已经被 nginx 占用，加一段：

```nginx
location /res/ {
    alias /path/to/server/res/;
}
```

腾讯云轻量服务器还要在控制台“防火墙”里放行 8686 端口。

## 资源目录结构

```
res/
  catalog.json                  # 科目 → 课本 → 单元目录
  english/pep3a/u1/
    manifest.json               # 本单元所有文件和大小，APP 按它下载
    unit.json                   # 课文分句、单词、知识点、题目
    pages/p2.jpg …              # 课本页面
    audio/*.mp3                 # 课文音频
    words/*.mp3                 # 单词发音
    tests/*.mp3                 # 试卷听力（每题一段）
```

要更新某个单元的内容：改好文件后，重新生成 `manifest.json`，并把 `catalog.json` 里这个单元的 `version` 加 1，APP 会提示“更新”。

`tools/seg.py` 是按停顿切分音频的小工具，用来给课文做分句时间轴。
